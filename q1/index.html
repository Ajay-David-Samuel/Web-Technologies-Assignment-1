How the Web Works

1. The Internet in Brief

The Internet is the physical and logical network of cables, routers, and satellites that lets computers around the planet exchange data. The Web is just one of the services built on top of it.

Home Router → ISP → Internet Exchange → Destination Server

Everyday services riding on the Internet include:

  • Web Browsing
  • Video Calls
  • Cloud Storage
  • Online Gaming
  • Email

2. Networking Building Blocks

A network is simply devices wired or wirelessly linked so they can talk to one another.

Key Terms

  • Device / Node: Anything that can send or receive data (laptop, phone, printer).
  • IP Address: The numeric label assigned to a device on a network.
  • Router: Directs traffic between different networks.
  • Access Point: Lets wireless devices join a network.
  • Protocol: The agreed format for exchanging data, e.g. HTTP or FTP.
Phone → Access Point → Router → Internet → Cloud Service

3. Breaking Down a URL

URL stands for Uniform Resource Locator — the address typed to reach a resource on the Web.

https://shop.cloudnest.io/deals/summer-sale
  • https: Protocol used for the connection
  • shop: Subdomain
  • cloudnest.io: Domain name
  • /deals/summer-sale: Path to the specific page

4. What's in a Domain Name

A domain name replaces a hard-to-remember IP address with a readable name.

www.greenvalley.org
  • www — Subdomain
  • greenvalley — Registered name
  • .org — Top-level domain

5. Browsers and Servers

Web Browser

Software that requests a page and displays it to the user — e.g. Chrome, Firefox, Brave, Safari.

Web Server

The machine and software that store site files and reply to browser requests — e.g. Apache, Nginx, LiteSpeed.

Browser --request--> Server
Server --response--> Browser

6. Journey of a Page Load

  1. Visitor types an address or taps a link.
  2. Browser looks up the domain's IP address using DNS.
  3. Browser opens a connection to that server.
  4. Browser sends an HTTP(S) request for the page.
  5. Server finds the requested files and builds a response.
  6. Server returns the page data to the browser.
  7. Browser paints the HTML, CSS, and JavaScript on the screen.
Visitor → Browser → DNS → Server → Response → Page Displayed

Summary

Networks, browsers, servers, domain names and scripting each play a distinct role, and together they turn a typed address into a rendered page in a fraction of a second.
